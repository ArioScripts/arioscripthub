# Ario Scripts Hub

Build ARIO SCRIPTS: a modern dark-theme script database platform. Include public script discovery with search, category/game filters, sorting, and pagination; script detail pages with Mac-style Lua code viewer (copy and .lua download with count increments), YouTube showcase embeds, and script images; user authentication, profiles, favorites, and script reporting; and a comprehensive role-based admin dashboard with analytics stats, script CRUD, category management, user management with ban/unban system and role controls, report moderation, admin audit logs, and dynamic site settings. Include Supabase database schemas, RLS policies, and client architecture.
